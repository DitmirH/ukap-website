# Agent instructions

All instructions for working on this project are in **[CLAUDE.md](./CLAUDE.md)** — read it before
making changes. Brand rules are in **[docs/BRAND.md](./docs/BRAND.md)**.

Key rules: don't commit/push unless asked; follow the brand guide (gold + black lead, blue + coral
accents, tokens only — no hard-coded hex); keep Sanity fallbacks; verify with `npm run build` and a
visual check at desktop and mobile widths.
